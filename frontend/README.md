# Calculadora Conexa

Frontend da calculadora comercial de custos WhatsApp, construído com React, TypeScript, Vite, Tailwind CSS e Zustand.

Todo o estado é mantido em memória no navegador. O projeto não possui backend, autenticação, API ou persistência.

## Executar

```bash
yarn
yarn dev
```

## Validar

```bash
yarn typecheck
yarn build
```
